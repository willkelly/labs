* Executive Summary

This report provides a comprehensive testing strategy and identifies additional concerns for the packages/memory SQLite-based persistence layer. Key findings:

1. *Current Testing*: Tests exist but lack migration-specific and backward compatibility tests
2. *Database Configuration*: No PRAGMA statements found - foreign keys may not be enforced by default
3. *Migration System*: Basic migration framework exists but lacks robust testing
4. *Concurrency*: Sequential execution pattern implemented but no formal concurrency tests
5. *Critical Gaps*: Missing foreign key enforcement, no WAL mode, limited error recovery testing

** 2. Migration Safety Testing

*** Current Migration System

**** Migration Structure (packages/memory/migrate.ts)
#+BEGIN_SRC typescript
// Migration 000: Setup migration tracking table
// Migration 001: Drop maybe_datum, restructure tables
// Migration 002: Remove COALESCE, make 'is' NOT NULL
#+END_SRC

**** Migration Characteristics
- Uses numbered migration files (000-, 001-, 002-)
- Wrapped in transactions (~db.transaction(migrate)~)
- Tracks migration history in ~migration~ table
- Reads migration status: ~SELECT * FROM migration ORDER BY id DESC LIMIT 1~

**** Migration Concerns
1. *No rollback mechanism* - Migrations only go forward
2. *Archive pattern* - Creates _archive tables, drops after migration
3. *Foreign key handling* - Recreates tables and constraints
4. *Data migration* - Uses INSERT SELECT with LEFT JOINs

*** Can We Add PRAGMA/WAL Without Breaking Existing Databases?

**** Analysis: Adding PRAGMA Statements

***** PRAGMA foreign_keys = ON
#+BEGIN_EXAMPLE
Risk Level: LOW to MEDIUM
Backward Compatible: YES (if no existing violations)
#+END_EXAMPLE

- Can be added safely *IF* existing data has no FK violations
- Should be added at database open time, not in schema
- Recommendation: Add to ~Space.open()~ and ~Space.connect()~

#+BEGIN_SRC typescript
// In space.ts, after database creation:
database.exec("PRAGMA foreign_keys = ON;");
#+END_SRC

***** PRAGMA journal_mode = WAL
#+BEGIN_EXAMPLE
Risk Level: MEDIUM
Backward Compatible: MOSTLY YES
#+END_EXAMPLE

- Creates additional ~-wal~ and ~-shm~ files
- Existing databases can be converted
- *Potential Issue*: Some file systems don't support WAL
- *Rollback*: Can switch back to DELETE journal mode

#+BEGIN_SRC typescript

#+END_SRC

***** Migration Strategy for WAL
1. *Optional Migration*: Create migration 003-enable-wal.sql
2. *Test on copy*: Always test on database copy first
3. *Graceful fallback*: If WAL fails, continue with DELETE mode

** 2. Concurrency and Race Conditions

*** Identified Concurrency Pattern

*File*: ~packages/memory/memory.ts~
*Lines*: 66-77

#+BEGIN_SRC typescript
/**
 * Runs task one at a time, this works around some bug in deno sqlite bindings
 * which seems to cause problems if query and transaction happen concurrently.
 */
async perform<Out>(task: () => Promise<Out>): Promise<Out> {
  return await traceAsync("memory.perform", async (_span) => {
    const result = this.ready.finally().then(task);
    this.ready = result.finally();
    await this.ready;
    return await result;
  });
}
#+END_SRC

*Analysis*:
- ✅ *Good*: Serializes operations to avoid Deno SQLite bugs
- ⚠️  *Concern*: Comment indicates workaround for known bug
- ❌ *Issue*: No timeout mechanism - long operations block everything
- ❌ *Issue*: No priority queue - all operations equal priority

*** Race Condition: Multiple Spaces

*Scenario*:
#+BEGIN_EXAMPLE
Process A: Opens space1, performs transaction
Process B: Opens space1 simultaneously, performs transaction

Without proper locking, both might succeed but create conflicts.
#+END_EXAMPLE

*Current Mitigation*:
- SQLite provides transaction-level locking
- ~session.store.transaction()~ wrapper ensures atomicity

*Potential Issue*:
- WAL mode allows concurrent readers, but writers still exclusive
- Multiple processes accessing same database need OS-level file locking

const RETRYABLE_CODES = ["SQLITE_BUSY", "SQLITE_LOCKED", "SQLITE_IOERR"];
const MAX_RETRIES = 3;
const RETRY_DELAY_MS = 100;

const executeWithRetry = async (
  fn: () => Result,
  retries: number = MAX_RETRIES
): Promise<Result> => {
  try {
    return fn();
  } catch (error) {
    const sqliteError = error as SqliteError;
    
    if (RETRYABLE_CODES.includes(sqliteError.code) && retries > 0) {
      await sleep(RETRY_DELAY_MS * (MAX_RETRIES - retries + 1));
      return executeWithRetry(fn, retries - 1);
    }
    
    throw error;
  }
};

  private requests: Map<string, number[]> = new Map();
  
  checkLimit(did: string, config: RateLimitConfig): boolean {
    const now = Date.now();
    const recent = this.requests.get(did)?.filter(

export interface BackupOptions {
  destination: URL;
  compress?: boolean;
  verify?: boolean;
}

export const backup = async (
  session: SpaceSession,
  options: BackupOptions
): Promise<Result<BackupInfo, Error>> => {
  const { store } = session;
  
  // Use SQLite backup API
  const backupDb = new Database(options.destination.pathname, {
    create: true
  });
  
  try {
    // Copy database using backup API
    store.exec(`VACUUM INTO '${options.destination.pathname}'`);
    
    // Verify integrity of backup
    if (options.verify) {
      const integrity = backupDb.prepare("PRAGMA integrity_check").get();
      if (integrity.integrity_check !== "ok") {
        return { error: new Error("Backup verification failed") };
      }
    }
    
    return {
      ok: {
        path: options.destination.pathname,
        timestamp: Date.now(),
        size: await Deno.stat(options.destination).then(s => s.size)
      }
    };
  } finally {
    backupDb.close();
  }
};

export const restore = async (
  backupPath: URL,
  destination: URL
): Promise<Result<void, Error>> => {
  // Verify backup integrity before restore
  const backup = new Database(backupPath.pathname, { create: false });
  const integrity = backup.prepare("PRAGMA integrity_check").get();
  backup.close();
  
  if (integrity.integrity_check !== "ok") {
    return { error: new Error("Backup file is corrupted") };
  }
  
  // Copy backup to destination
  await Deno.copyFile(backupPath.pathname, destination.pathname);
  
  return { ok: undefined };
};

#+BEGIN_SRC typescript
export interface HealthCheck {
  healthy: boolean;
  checks: {
    integrity: boolean;
    foreignKeys: boolean;
    indexes: boolean;
  };
  warnings: string[];
  errors: string[];
}

export const healthCheck = async (
  session: Session
): Promise<HealthCheck> => {
  const warnings: string[] = [];
  const errors: string[] = [];
  
  // Check 1: Database integrity
  const integrityResult = session.store.prepare(
    "PRAGMA integrity_check"
  ).get();
  const integrity = integrityResult.integrity_check === "ok";
  
  if (!integrity) {
    errors.push(`Integrity check failed: ${integrityResult.integrity_check}`);
  }
  
  // Check 2: Foreign key violations
  const fkViolations = session.store.prepare(
    "PRAGMA foreign_key_check"
  ).all();
  const foreignKeys = fkViolations.length === 0;
  
  if (!foreignKeys) {
    errors.push(`${fkViolations.length} foreign key violations found`);
  }
  
  // Check 3: Index integrity
  const indexes = session.store.prepare(
    "SELECT name FROM sqlite_master WHERE type='index'"
  ).all();
  const expectedIndexes = ["memory_the", "memory_of", "fact_since"];
  const indexesOk = expectedIndexes.every(name =>
    indexes.some(idx => idx.name === name)
  );
  
  if (!indexesOk) {
    warnings.push("Some indexes are missing");
  }
  
  // Check 4: Database stats
  const stats = collectDatabaseStats(session);
  if (stats.size > 1_000_000_000) { // 1GB
    warnings.push("Database size exceeds 1GB");
  }
  
  return {
    healthy: integrity && foreignKeys && indexesOk && errors.length === 0,
    checks: { integrity, foreignKeys, indexes: indexesOk },
    warnings,
    errors
  };
};
